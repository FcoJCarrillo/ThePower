# Proyecto SQL

## Descripción

Proyecto realizado con PostgreSQL en el que se han resuelto diferentes ejercicios mediante consultas SQL sobre una base de datos proporcionada.

El objetivo ha sido practicar la extracción y análisis de datos utilizando distintas sentencias SQL.

## Herramientas utilizadas
PostgreSQL
DBeaver
Git y GitHub

## Pasos realizados
Exploración de la base de datos para conocer las tablas y sus relaciones.
Análisis de los enunciados de los ejercicios.
Desarrollo de las consultas SQL necesarias para resolver cada ejercicio.
Comprobación de los resultados obtenidos en DBeaver.
Organización y documentación de las consultas realizadas.
## Conceptos trabajados
Las diferentes formas con trabajar con SQL desde traer datos de tablas con select sencillos hasta la creación de vistas y traer datos realcionando datos de distintas tablas.

## Análisis

Este proyecto me ha permitido mejorar el manejo de SQL y comprender mejor cómo obtener información de una base de datos relacional.

Durante la realización de los ejercicios he trabajado con consultas simples y complejas, aprendiendo a relacionar tablas y a filtrar información según distintos criterios.

## Conclusiones

La práctica ha sido útil para reforzar los conocimientos de SQL y ganar soltura en el uso de PostgreSQL y DBeaver para el análisis y consulta de datos.
